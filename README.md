# Agribusiness Performance Analysis Using SQL

## Project Overview
This project analyzes the performance of a hypothetical agribusiness using SQL and Python in Google Colab.

## Objectives
- Analyze crop production efficiency.
- Calculate average yield per acre.
- Evaluate operational costs.
- Compare seasonal production trends.
- Calculate revenue and operating profit.
- Generate charts and business insights.

## Dataset
- `farms.csv` – Farm details.
- `production.csv` – Crop production and operational costs.

## Tools Used
- SQL (SQLite)
- Python
- Google Colab
- Pandas
- Matplotlib

## Key Performance Indicators
- Yield per acre
- Cost per kilogram
- Total revenue
- Operating profit
- Profit margin
- Seasonal production trends

## Project Files
- Google Colab notebook
- SQL scripts
- CSV datasets
- Detailed analysis report
- Visualization charts

## Conclusion
The project demonstrates how SQL can help evaluate agribusiness performance and support data-driven business decisions.

**Note:** The dataset used in this project is hypothetical and created for educational purposes.
